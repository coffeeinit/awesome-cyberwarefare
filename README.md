## 9. Key Patterns & Lessons

| Pattern | Observation |
|---|---|
| **Supply chain attacks are the new frontier** | SolarWinds, MOVEit, Snowflake, Notepad++, PolinRider — one compromise cascades to thousands |
| **Critical infrastructure is the top target** | 312+ ICS incidents; water, energy, healthcare most targeted |
| **Ransomware is a national security threat** | Colonial Pipeline, Change Healthcare, Jaguar Land Rover |
| **State actors use criminal proxies** | Russia uses DarkSide, LockBit; North Korea uses Lazarus, ShinyHunters |
| **Wipers are more dangerous than ransomware** | NotPetya, Shamoon, DynoWiper — designed for destruction, not extortion |
| **AI is now a weapon** | Deepfake job interviews, AI-generated decoys, LLM-powered attacks |
| **Legitimate services are repurposed** | GitHub, GitLab, OneDrive, Telegram, Discord as C2 |
| **Credential theft dominates** | Stolen credentials, missing MFA, OAuth abuse |
| **Transparency is declining** | 76% of 2026 breach notices omitted attack vector |
| **Cyber warfare is now conventional warfare** | Ukraine, Israel-Iran, US-China all use cyber as first strike |
| **Crypto is the new bank vault** | Bybit $1.5B; North Korea stole $2.7B in 2025 alone |
| **OT is converging with IT** | Sandworm pivots from IT to OT; PLC-level attacks increasing |
